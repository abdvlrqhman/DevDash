2 · Claude sessions

Sessions run on the VPS under your own Linux user and keep running when you close the phone. Chat is the default. Bypass permissions is on by default. Remote Control is an optional switch.

A plain shell on the server, separate from Claude and from projects. Your own user by default. The admin shell needs 2FA every time and has a red header so you never mix them up.

Same screens, with a sidebar instead of the bottom nav. Claude chat gets the session list on the left and the files it touched on the right.
